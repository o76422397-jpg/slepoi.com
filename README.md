Слепой.com
Это мой проект для школы. Я сделал сайт, который помогает людям.

Что делает сайт:
Можно задать вопрос и получить ответ от ИИ
Можно посмотреть погоду в разных городах Украины
Можно спросить у судьбы что-то про будущее

Почему я это сделал:
Мне показалось, что людям иногда хочется с кем-то поговорить или что-то спросить, но не всегда есть с кем. Вот и мы придумал такого помощника. Плюс погоду удобно смотреть в одном месте.

Как это работает:
Я написал сайт на Python и Streamlit. Для ответов ИИ использую Gemini API. Для погоды беру данные с Open-Meteo.

Файлы в проекте:
app.py — главный код сайта requirements.txt — список библиотек, которые нужны README.md — этот файл с описанием

Как запустить:
py -m streamit run app.py
